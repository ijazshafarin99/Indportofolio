# Personal Portfolio Website Template

Repositori ini berisi *source code* untuk website portofolio pribadi[cite: 1]. Template ini dirancang untuk menampilkan profil profesional, riwayat pendidikan, serta etalase proyek dengan tampilan yang bersih dan responsif. 

**Penggunaan Template:**
Anda bebas untuk melakukan *clone*, meniru, memodifikasi, dan menggunakan template website portofolio ini untuk kebutuhan pribadi Anda. 

## Struktur Menu
Template ini mencakup beberapa bagian (seksi) navigasi utama yang dapat disesuaikan dengan data Anda, antara lain:

*   **About:** Ringkasan profil, status profesional, serta tombol interaktif untuk mengunduh CV dan kontak[cite: 2].
*   **Education:** Bagian untuk menampilkan riwayat pendidikan[cite: 2].
*   **Experience:** Bagian untuk mencantumkan pengalaman kerja atau profesional[cite: 2].
*   **Skills:** Visualisasi persentase kemampuan teknis, *software*, dan *hardware* yang dikuasai[cite: 2, 3].
*   **Projects:** Etalase kartu proyek yang telah dikerjakan beserta deskripsi dan tag teknologi yang digunakan[cite: 2, 4].
*   **Certificates:** Galeri sertifikasi dan penghargaan[cite: 2].
*   **Org:** Riwayat pengalaman organisasi[cite: 2].
*   **Contact:** Informasi kontak untuk perekrut atau klien[cite: 2].

## Cara Menggunakan
1. Lakukan *clone* atau unduh repositori ini.
2. Buka folder proyek dan modifikasi konten teks, gambar, serta tautan (*link*) agar sesuai dengan profil Anda.
3. *Deploy* ke platform *hosting* statis pilihan Anda (misalnya GitHub Pages, Netlify, atau Vercel).
